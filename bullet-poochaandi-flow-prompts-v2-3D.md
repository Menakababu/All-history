Song: "Urulaikizhangu Chella Kutty" (Tamil, 3:16 = 196 s)
Cast: **Amma**, **Urulaikizhangu Chella Kutty** (potato kid), **Bullet Poochaandi** (your attached image = design reference)

## What changed from v1

1. **3D animated feature-film look** (glossy toy-like textures, big expressive eyes) instead of dark painterly.
2. **Flow-safe wording.** Removed every word that can trigger a filter: scary, terrified, evil, threatening, wicked, gulp, bath nudity, weapons (rolling pin), brand/studio names. Poochaandi is now a **funny, mischievous, friendly "bogeyman"**: he is all show and the kid is delighted, not frightened. Kid reactions are giggling, wide-eyed, peeking through fingers.
3. **Kid-hooks** added (Section "Hooks"): a copyable signature dance, a recurring gag in every verse, and a payoff ending.
4. Same timing and scene numbering, so your editing plan from v1 still works.

## Flow-safety rules (follow these for every prompt)

- Keep the opening line of every prompt: `Family-friendly, G-rated, cheerful comedy.`
- Describe feelings positively: "excited", "giggling", "playfully peeking through fingers". Never "scared / terrified / afraid / evil / threatening".
- Poochaandi never touches, chases or reaches for the child. He performs, dances and winks from a distance.
- No studio or brand names, no real people, no readable text/logos.
- The child is always fully clothed (the "bath" scene is a bubble-foam raincoat party).
- If Flow still blocks a prompt, delete "fire/flames" first and use "magical orange sparkles", then retry.
- Upload the reference image of Poochaandi once and reuse it. Say "turn the reference into a friendly 3D animated character" in the first generation, then use that 3D result as the reference from then on.

## Hooks (this is what makes kids go crazy)

**1. The first 3 seconds (S1).** Poochaandi's bike jumps out of a glowing portal straight at the camera in a wheelie, then freezes in a big grin and winks. Kids need a bang in 3 seconds.

**2. The "Bullet Bounce" signature dance (3 moves kids can copy).** Used in EVERY chorus clip (b):
- Move 1: **REV, REV**: both fists twist the handlebar twice.
- Move 2: **WHEELIE**: the front wheel pops up, the feather crown bounces.
- Move 3: **FREEZE + WINK**: points at the camera with a big grin.
Say this in every chorus prompt so it stays the same dance throughout.

**3. Running gags (one per verse so every verse is a surprise).**
- Kutty's green sprout on the hood wiggles when he is excited.
- Poochaandi's peacock feathers change color (pink → blue → gold) on each beat.
- The skull headlight blinks like an eye and sometimes sneezes a puff of glitter.
- In every "c" clip, Kutty and Amma do a tiny high-five and Poochaandi hides half behind something, giggling.

**4. Payoff ending (S26).** Poochaandi turns out to be a friend: he gives Kutty a gentle high-five and everyone dances together. This is what makes people replay.

**5. Thumbnail / cover frame.** Use S3 (portal + wheelie) and keep the Poochaandi grin centered.

**6. Shorts cut-down.** For a 15–20 s teaser use: S1 + S3 + S9 + S24 + S26.

## Workflow in Flow

1. Generate the 3 character sheets first (Step 1). For Poochaandi, upload your image and say "turn this into a friendly 3D animated character, same costume".
2. Generate each scene image with the character sheets attached as references.
3. Image to Video using the scene image as the first frame and the matching video prompt.
4. Veo cannot lip-sync to the song. Prompts say "no music, no speech" so the audio stays clean. Mouths move as if singing; add a lip-sync tool later if you want exact sync.
5. Flow's native lengths are 4/6/8 s. For the "10 s" clips, generate 8 s and extend it, or slow it to about 80 %.

# Editing tips

- Place clips using the times in each heading, then slide by ear.
- Add a flash/whoosh transition and a small zoom-in on each REV, REV for extra punch.
- If a block feels short, add B1–B4 or repeat the chorus clip (b) with a different crop.
- Verses 5 and 6 share lyrics, so S14–S16 and S17–S19 use different locations on purpose.
